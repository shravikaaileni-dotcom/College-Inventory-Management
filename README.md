# College Inventory Management System

A web-based College Inventory Management System developed using HTML, CSS, JavaScript, Node.js, Express.js, and MySQL.

## Project Modules
- User Authentication
- Item Management
- Issue Management
- Return Management
- Low Stock Alerts
- Inventory Reports

## Team Work Distribution
- Member 1: Backend and Database Development
- Member 2: Frontend and Dashboard Development

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: MySQL
- Charts: Chart.js
